I'm a Python developer with a genuine interest in how AI and machine learning are changing the way software gets built. My background is in applied Python — GUIs, REST API integrations, data pipelines, and CLI tools — and I'm channeling that foundation into learning AI/ML hands-on.

## 🧭 Why AI Product Engineering

Most of my hands-on Python work has been product-shaped from the start — GUIs, API clients, CLI tools people actually run. AI Product Engineering is the natural next step: instead of just learning ML in isolation, I want to learn how to wrap models and data pipelines into real, usable products.

- 🧩 **Backend/data layer** — currently learning PostgreSQL specifically for AI workloads (JSONB, pgvector, embeddings, hybrid full-text + vector search) rather than general SQL
- 🔌 **Integration layer** — comfortable wiring up REST APIs (OpenWeatherMap, LLM APIs) and building CLI/GUI tools around them
- 🎨 **Product layer** — next skill gap to close is front-end (React/TypeScript), to eventually ship full-stack AI products, not just backend scripts
- 🚀 **North star** — go from "Python developer learning ML" to someone who can take an LLM/ML capability and turn it into a working product end-to-end
